# v0.1.2 findings

Changes since v0.1.1 (released 2026-11-01), with causes. Issues carry the details.

- **One visible panel is always active (issue #35).** A second panel appearing while the console had focus left focus in the console, so the active panel looked inactive. `Core/Panels/PanelVisibilityRule` keeps the panel that was already visible active and gives it focus. Commit bc3151b.

- **Size column in Medium and background folder sizes (issues #36, #37).** Medium is Name | Size | Name | Size. Folder sizes are counted on one background thread (lowest priority, background I/O mode), visible folders first, local fixed drives only, into one cache shared with F3 and the selection totals. A long count pauses for the other panel's visible folders and resumes later. Commits 0ed9c95, 9fcd3ee.

- **Ctrl+Q / Ctrl+L show a hidden panel (issue #38).** With one panel shown, they show the other panel with quick view / info and hide it again on the second press; they also work at the idle prompt. Commits 325a66f, fa198ac.

- **Alt quick search appends (issue #39).** Any key the quick search did not know closed it, so each Alt+letter started a new search. Alt+letters and plain letters now append. Commit e6b39e6.

- **Column headers in Medium (issue #40).** The header row was drawn only for one-column modes. Commit 00928a8.

- **Windows context menu (issue #41).** Right click, Shift+F10 and the Menu key show the shell's context menu (`Panels/ShellContextMenu`: `IShellFolder.GetUIObjectOf` / `CreateViewObject` for `IContextMenu`, `IContextMenu2/3` messages for owner-drawn submenus, `TrackPopupMenuEx`, `InvokeCommand`).
  - Right click no longer toggles the selection (owner's choice, unlike Far); Ctrl+click does.
  - Target: the selection when the clicked item is marked (keys: when anything is marked), else the item; empty space or ".." gives the folder's background menu.
  - The shell's "Rename" verb needs an Explorer view, so it runs the panel's Shift+F6 when the menu covers the same items.
  - Checked in a test copy: menus on a file, on empty space and by Shift+F10; Esc without side effects; Copy as path; Rename opening the Shift+F6 dialog; Delete of one unmarked item and of a two-item selection (the panel refreshed by itself).
  - Not checked: the Menu key (no such key here), high DPI menu position, several monitors. Some PowerToys entries appear twice; they come from the shell extensions themselves.

- **Far Manager theme (issue #42).** Built-in `far.json` (`"theme": "far"`): navy panels, aqua text and frames, white folder icons, yellow marked files, teal cursor with black text, teal title bar, black terminal with the legacy console palette. `ThemeLoader.KeepsOwnAccent` keeps the Windows accent from tinting its cursor. Detail columns (size, dates) on the focused cursor row now use the selection colour like the name; with the Far theme they were aqua on teal. Checked in a test copy with Consolas: panels, marked files, cursor row, F7 dialog, F9 menu. Not part of the theme: the font (set `panels.fontFamily` to Consolas), Far's grey dialogs, and different colours for folder and file names.
